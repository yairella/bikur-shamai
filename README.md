# ביקור שמאי

אפליקציית שטח לביקור שמאי מקרקעין בדירות של פרויקט פינוי בינוי, במסגרת עבודת הניקוד לסדר בחירת הדירות החדשות.
המטרה: תיעוד אחיד בתמונות של כל מרכיבי כל דירה.

## מה האפליקציה עושה

- פרויקט, ובתוכו רשימת דירות. אפשר להוסיף דירה בודדת או טווח מספרים בבת אחת.
- פרטי דירה: בעלים, קומה, חדרים, שטח רשום ושטח שנמדד, כיווני אוויר, נוף, מצב תחזוקה, הערות.
- הרכב הדירה (חדרי שינה, חדרי רחצה, מרפסות, ממ"ד, גינה, גג, חניה, מחסן, תוספות). רשימת הצילומים נבנית לפי ההרכב.
- רשימת צילום קבועה של 18 מרכיבים ממוספרים, עם הוראת צילום לכל צילום וסימון צילומי חובה.
- פס זיהוי אחיד בתחתית כל תמונה: הדירה, המרכיב, סוג הצילום, התאריך והשעה.
- סימון "אין גישה / לא קיים" עם סיבה, והערה לכל מרכיב.
- סרגל התקדמות ורשימת צילומי חובה חסרים.

## הפקה

- דוח להדפסה או לשמירה כקובץ, לדירה אחת או לכל הפרויקט.
- טבלת סיכום לאקסל.
- קובץ מרוכז: תיקייה לכל דירה עם שמות קבצים קבועים, דוח שנפתח בכל דפדפן, טבלת סיכום, וקובץ גיבוי שאפשר לשחזר ממנו את העבודה במכשיר אחר.

## פרטיות ואחסון

כל הנתונים והתמונות נשמרים רק בדפדפן של המכשיר, ולא נשלחים לשום שרת.
מומלץ להוריד קובץ מרוכז בסוף כל יום עבודה, כגיבוי.
האפליקציה עובדת גם בלי קליטה, ואפשר להוסיף אותה למסך הבית של הטלפון.

## הפעלה

האפליקציה היא אתר סטטי, בלי שרת ובלי שלב בנייה. כדי לפתוח אותה בטלפון מפעילים אירוח דפים במאגר:
הגדרות המאגר, ואז דפים, ובוחרים את הענף הראשי ואת תיקיית השורש.
אחרי כדקה האפליקציה זמינה בכתובת שמופיעה באותו מסך.

שימו לב: אירוח דפים במאגר פרטי דורש מנוי בתשלום. במאגר ציבורי הקוד גלוי לכולם, אבל הנתונים עצמם נשארים במכשיר בכל מקרה.

## קבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | מבנה הדף |
| `app.js` | כל הלוגיקה: אחסון, רשימת הצילום, עיבוד תמונות, דוחות וקובץ מרוכז |
| `app.css` | עיצוב, כולל עיצוב הדוח להדפסה |
| `sw.js` | עבודה בלי חיבור לרשת. מעלים את מספר הגרסה בכל שינוי |
| `manifest.webmanifest` | התקנה למסך הבית |
| `fonts/` | גופני Heebo ו־Assistant |

את רשימת המרכיבים והצילומים משנים במשתנה `SECTIONS` בקובץ `app.js`.
